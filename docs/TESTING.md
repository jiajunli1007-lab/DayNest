# 测试记录和待验收事项

2026-10-30，在 Codex Windows AppContainer 中：

- Python 3.15.0、PySide6 6.12.0。自动测试覆盖 SQLite 持久化、日期隔离、无效备份拒绝、安全备份恢复、控件逻辑和完整应用离屏启动退出。
- `tools.check_windows` 检查 Windows Qt 平台的原生窗口可见状态、置顶标志开启与关闭；实际遮挡关系尚需人工检验。
- 系统托盘报告可用；托盘图标实际可见、点击、隐藏恢复及 Explorer 重启后恢复均未验收。
- 全局快捷键在当前 AppContainer 注册失败：Windows 错误 5，拒绝访问。占用是错误 1409；不要把错误 5 误报成占用。普通窗口和托盘入口保留。用户普通 PowerShell 的注册及实际按键效果未测试。
- `daynest.desktop_probe` 只读发现 Progman、WorkerW 和 SHELLDLL_DefView；Codex AppContainer 的挂接实验遇到 Windows 错误 5。普通 PowerShell 首次父关系改变但退出报告恢复样式警告；修复后同进程原生窗口测试通过，用户重测报告 Explorer 宿主下父关系改变且恢复检查通过。用户没有观察视觉层级或图标交互，不能证明真正壁纸层工作。
- 当前离屏 Qt 环境报告字体家族为 0，预览出现方框，不能据此判断用户普通桌面的字体显示。
- 首次 PyInstaller 冒烟测试发现误收集外部 Poppler 的 `icuuc.dll`，该库缺少 Qt 所需的 Windows ICU 导出，导致 QtCore 加载失败；移走该诊断包内的误收集库后，程序启动并创建测试数据库。构建脚本使用局部子进程 PATH 防止这一误收集，并拒绝交付包含该文件的结果。

真实桌面验收：检查窗口文字、透明度、拖动、尺寸、普通/置顶遮挡、托盘点击与退出、Ctrl+Alt+N、Win+D、多屏缩放、休眠和 Explorer 恢复。未实测项不得宣称通过。

2026-10-31，桌面组件改版：13 项基础测试及组件位置测试通过，包含三种固定尺寸、拖动位置保存、待办同步、背景 0/35/70/100% 的像素 alpha 和文字窗口不透明度。Windows Qt 平台的原生 Z 顺序探针中，测试普通窗口位于组件之前，组件位于 Shell 之前；这不是 Win+D、桌面图标或 WorkerW 壁纸层通过的证据。离屏效果图使用测试数据及模拟背景，不能证明用户壁纸下的实际效果。

公开分发前核验 Qt 及其第三方组件许可证、提供必要许可和替换库途径，并由用户确认项目授权及发布。PyInstaller 生成物的构建成功不等于其他电脑上的运行验证。
