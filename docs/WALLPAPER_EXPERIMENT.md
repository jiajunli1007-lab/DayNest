# 桌面壁纸层实验（待用户批准实际挂接）

稳定版始终以普通窗口启动。`experiments.desktop_layer` 是独立实验，不由主程序调用。

默认只读：

```powershell
.\.venv-diagnostic\Scripts\python.exe -m experiments.desktop_layer
```

候选规则：当前 Progman 必须同时拥有图标视图和唯一的 WorkerW 子窗口，否则退出；不会向 Explorer 发送 0x052C 消息。

## 需批准的操作

运行 `--attach` 将建立一个独立测试窗口，临时修改该测试窗口的样式，并将其父窗口设为候选 WorkerW。15 秒后尝试恢复原父关系和样式并关闭；异常路径也会尝试恢复。它不修改 Explorer 的窗口样式、注册表、壁纸文件或启动项。不保证 Explorer 的非公开层级或跨进程 DPI 行为在所有版本一致，因此不应在未保存其他工作的情况下运行。

验收须记录真实桌面视觉及结构：窗口在图标后且应用窗口可覆盖、Win+D 结果、桌面图标仍可点击、超时后实验窗口消失，确认正常应用窗口与桌面可继续使用。附着成功或找到句柄本身不构成通过。失败即记录并保留普通窗口模式；不自行重启 Explorer 或修改系统设置。

2026-10-30：Codex AppContainer 中执行 `--attach` 时 `SetParent` 返回错误 5（拒绝访问），未挂接。用户在普通 PowerShell 首次报告父窗口关系改变，但退出时出现样式恢复警告。之后调整为退出 Qt 事件循环前先恢复父关系和样式；同进程窗口的真实 Win32 挂接与恢复测试通过。用户在普通 PowerShell 重测报告父关系改变且恢复检查通过；用户没有观察窗口的实际视觉层级或图标交互，因此不能据此宣称真正壁纸层通过。
