## DayNest v0.1.0-preview

DayNest 是一款轻巧的 Windows 桌面日历、待办和便签应用。桌面组件支持透明度和尺寸调整，可以在日历中查看事项，并为待办设置提醒和重复规则；数据保存在本机。

### 如何体验

1. 下载发布页中的 Windows 64 位便携 ZIP，解压整个压缩包。
2. 打开解压后的 `DayNest` 文件夹，双击 `DayNest.exe`。请将 `_internal` 文件夹和程序一起保留。
3. 使用组件右上角菜单选择尺寸、透明度和窗口层级；点击日历日期添加事项。

程序不要求单独安装 Python。预览包尚未经过代码签名，Windows 可能会显示安全提示；请从项目官方发布页下载，并核对发布页提供的 SHA-256。

### 使用前了解

- 提醒只在程序运行期间检查，关机、睡眠或退出后不会弹出。
- 窗口“靠后”不是 Windows 真正的壁纸层；多显示器、缩放、Win+D、托盘和快捷键等行为仍需要更多设备验证。
- 数据通常保存在 `%LOCALAPPDATA%\DayNest`，可在管理窗口中备份和恢复。
- 测试过 Windows 11 本机启动和基本自动测试；其他电脑、Windows 版本及安全软件的兼容性仍需验证。
